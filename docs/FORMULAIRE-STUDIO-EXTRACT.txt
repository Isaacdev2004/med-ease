1.  Principe  UX  du  MVP  
Je  partirais  sur  un  même  modèle  pour  tous  les  formulaires  :  
Créer  /  Modifier  →  renseigner  →  prévisualiser  →  enregistrer  →  confirmer  
Avec  :  
●  champs  obligatoires  marqués  *  ●  listes  déroulantes  plutôt  que  saisie  libre  lorsque  possible  ●  cases  à  cocher  ●  boutons  Oui  /  Non  ●  recherche  ●  valeurs  par  défaut  ●  possibilité  de  modifier  ultérieurement  ●  autosave  ou  brouillon  ●  barre  de  progression  lorsque  le  formulaire  est  long  ●  résumé  avant  validation
